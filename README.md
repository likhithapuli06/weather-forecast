# 🌤️ Weather Forecast Website

A responsive weather forecast web application built with ReactJS that displays current weather conditions and a 7-day forecast. Users can search for any city or automatically detect their location to view weather information.

## ✨ Features

* 🔍 Search weather by city name
* 📍 Detect weather using current location
* 🌡️ Display current temperature and feels-like temperature
* 💧 Show humidity and wind speed
* 📅 7-day weather forecast
* 🌤️ Weather conditions with icons
* ⚠️ Error handling for invalid cities and location permissions
* 📱 Responsive design for desktop and mobile devices

## 🛠️ Technologies Used

* ReactJS
* JavaScript
* HTML5
* CSS3
* Open-Meteo API
* Vite

## 🚀 Getting Started

### 1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

### 2. Navigate to the project

cd weather-forecast

### 3. Install dependencies

npm install

### 4. Start the development server

npm run dev

Open the local URL shown in the terminal to view the application.

## 🌐 Weather API

Weather data is provided by **Open-Meteo**, which provides weather information without requiring an API key.
